## API

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| items | 数据列表 | `any[]` | - |
| itemHeight | 每项高度 | `number` | `36` |
| height | 容器高度 | `number` | `240` |
| renderItem | 渲染函数 | `(item) => ReactNode` | - |
