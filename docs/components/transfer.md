## API

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| dataSource | 数据源 | `TransferItem[]` | - |
| targetKeys | 右侧已选 key 列表 | `string[]` | - |
| defaultTargetKeys | 默认已选 key 列表 | `string[]` | - |
| onChange | 变化回调 | `(targetKeys) => void` | - |
