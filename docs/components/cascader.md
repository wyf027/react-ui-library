## API

| 属性 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| options | 级联数据 | `CascaderOption[]` | - |
| value | 当前值 | `string[]` | - |
| defaultValue | 默认值 | `string[]` | - |
| onChange | 变化回调 | `(value) => void` | - |
